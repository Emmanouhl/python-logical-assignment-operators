# Logical Operators and Assignment Operators in Python

A focused study of Python's logical operators for complex condition evaluation and assignment operators for efficient variable updates.

## What I Learned

### Logical Operators
- **and** – Requires both conditions to be True
- **or** – Requires at least one condition to be True
- **not** – Reverses the Boolean value of a condition
- Combining multiple logical conditions for complex decision-making
- Short-circuit evaluation and performance implications
- Precedence of logical operators in compound conditions

### Assignment Operators
- **=** – Standard assignment
- **+=** – Add and assign
- **-=** – Subtract and assign
- ***=** – Multiply and assign
- **/=** – Divide and assign
- **//=** – Floor divide and assign
- **%=** – Modulus and assign
- ***=** – Exponentiate and assign

## Key Skills Acquired

- Building complex conditional statements with multiple criteria
- Using logical operators to create sophisticated decision trees
- Writing concise code with compound assignment operators
- Combining logical and comparative operators effectively
- Debugging logical expression errors and edge cases
